# TNT — Multi-omics analysis code

Analysis code for a multi-omics study of **total neoadjuvant therapy (TNT) response in
microsatellite-stable rectal cancer**. Patients received short-course radiotherapy
(SC-RT, 25 Gy / 5 fractions) followed by consolidation FOLFOX/CAPOX (N = 35; WES + RNA-seq,
with paired pre-/post-RT biopsies in a subset).

This repository contains **only the analysis code** used to produce the study's results.
It intentionally does **not** contain the manuscript, figures/tables, or sequencing data.

## What is (and isn't) here

- **Here:** Python / R / shell scripts for the full pipeline (WES, RNA-seq, statistics,
  machine learning, external-cohort meta-analysis, and figure generation).
- **Not here:**
  - Manuscript, cover letter, supplementary text (kept out of the repo by design).
  - Raw/intermediate sequencing data (BAM/FASTQ/VCF), figure/table outputs
    (PDF/PNG/PPTX/XLSX), and per-module result directories — all regenerated by the
    scripts below and excluded via `.gitignore`.
  - Sequencing data are deposited under controlled access (SRA/GEO); accessions are
    listed in the manuscript.

## Core pipeline (`scripts/`)

Run in numeric order; each step consumes upstream outputs.

**WES:** `02` pseudo-somatic → `04` Mutect2 → `05` SBS refit → `06` snpEff →
`07` variant master / TMB / drivers → `08` MSI → `11` HLA typing → `12` CNVkit →
`18` scarHRD → `19` PyClone → `21`/`37` HLA-LOH → `22`–`24` pVACseq neoantigens.

**RNA-seq:** `01` TPM + signatures → `09` DEG / GSEA → `10` CMS → `13` ssGSEA (hallmark) →
`15` TRUST4 (BCR/TCR repertoire).

**Integration & modelling:** `14` integration → `16` ML predictor →
`28` nested-CV + permutation → `20`/`29` paired pre-/post-RT delta →
`30` BH-FDR cascade → `35` bootstrap CIs.

**External validation:** `17`/`31` external cohorts → `32`/`33` CD8 axis + forest →
`34` external tables → `38` forest incl. Akiyoshi 2023.

Scripts numbered `25`–`26`, `36`, `39`–`57` and `fig*` generate the manuscript figures.

## Environment

Python via miniconda; R with Bioconductor (R 4.3.x / Bioconductor 3.18). Key external
tools: BWA, HISAT2, StringTie, GATK/Mutect2, snpEff, CNVkit, msisensor-pro,
SigProfilerAssignment, DESeq2, fgsea, CMScaller, TRUST4, OptiType, pVACseq, mhcflurry.
Exact tool versions are recorded in the manuscript's supplementary methods.
